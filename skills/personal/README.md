# Personal

Skills tied to my own setup: not promoted in the plugin, linked locally by `scripts/link-skills.sh`.

- **[telegram-message](./telegram-message/SKILL.md)**: Send any user-requested message to Seefs through Telegram.
- **[paseo-artifacts](./paseo-artifacts/SKILL.md)**: Keep a Paseo workspace's plans, notes, diagrams, screenshots and reports in one Artifacts collection the user can find any time.
- **[paseo-summary](./paseo-summary/SKILL.md)**: Write or refresh the summary Artifact for a Paseo goal or workspace from the conversation, the Desk and the Artifacts collection. User-invoked.
